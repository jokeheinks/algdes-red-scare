\subsection{None}

For problem None, we solved each instance using breadth-first search (BFS) from $s$.
The condition that no internal vertex is red means that a red vertex can only be the
first or the last vertex of the path. Put another way, the path may arrive at a
red vertex, but it may never leave one, except $s$ itself. So we change the graph:
let $H$ be $G$ with every edge leaving a red vertex $v \neq s$ removed (for an
undirected edge $uv$, only the direction from $v$ to $u$ is removed). Then the
$s,t$-paths in $H$ are exactly the $s,t$-paths in $G$ that internally avoid $R$.
All edges have length $1$, so a shortest such path is a shortest $s,t$-path in
$H$, and BFS finds that. We never build $H$. The BFS simply does not expand a red
vertex other than $s$: when it reaches one, the vertex gets its distance (so a
red $t$ can still be found), but its neighbours are not added to the queue.

This is correct because, in an unweighted graph, BFS from $s$ explores the
vertices in layers $0, 1, 2, \dots$, and layer $k$ holds exactly the vertices at
distance $k$ from $s$. So the first time $t$ is reached gives the length of a
shortest $s,t$-walk in $H$. A shortest walk never repeats a vertex, so it is a
path. Every internal vertex of this path is left along some edge of $H$, so it is
not red. This shows the BFS answer is the length of a valid path. In the other
direction, every valid path in $G$ uses only edges of $H$, so no valid path is
shorter than the BFS answer. If BFS never reaches $t$, there is no valid path,
and we return $-1$. The special cases follow directly: if $s = t$ the answer is
$0$, and if the edge $st$ is in $G$, then $t$ is in layer $1$ and the answer is
$1$, whatever the colours of $s$ and $t$.

Each vertex is expanded at most once, and each edge is looked at at most once per
direction, so the running time is $O(n + m)$. This works for every graph, directed
or undirected, so we found the exact answer for all instances. Our implementation
takes $0.23$ seconds on the instance common-2-5757, which has $n = 5757$ and
$m = 163671$, and $0.17$ seconds on the instance wall-n-10000, which has
$n = 80000$.
